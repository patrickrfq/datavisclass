As instruções de cada micro-tarefa estão em comentários dentro do próprio
arquivo. Abra o arquivo no editor de texto e no browser ao mesmo tempo.

**A tarefa 3 é a que vai para o GitHub Pages**: ao terminar, salve o arquivo
como `barras.html`, dentro da pasta `basic`.

### Como rodar

Em um terminal, dentro da pasta `basic`:

```
python3 -m http.server
```

Depois abra <http://localhost:8000> no browser.
